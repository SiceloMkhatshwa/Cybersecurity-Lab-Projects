# Cybersecurity-Lab-Projects

Performed penetration testing using Kali Linux and Nmap on vulnerable virtual machines, covering SQL Injection, XSS, DoS simulation, and keylogging concepts.
**Tools:** Kali Linux, Nmap, VirtualBox, Metasploitable

**Topics Covered:**
- Network reconnaissance and enumeration
- SQL Injection and Cross-Site Scripting (XSS)
- Denial-of-Service (DoS) simulation
- Keylogging and malware behaviour
**Skills:** Penetration Testing, Vulnerability Assessment, Ethical Hacking
